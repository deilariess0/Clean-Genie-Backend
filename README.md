# Clean Genie - Backend API

**Clean Genie** is a full-stack booking service management platform. This repository contains the **Backend API**, which serves as the robust engine powering both the Customer Frontend and the Admin Dashboard.

## 🛠️ Tech Stack

*   **Runtime:** Node.js
*   **Web Framework:** Express.js
*   **Database:** PostgreSQL (Hosted on Aiven.io)
*   **Hosting:** Render

## 🚀 Deployment

This API is deployed and hosted on Render with CI/CD (Continuous Integration/Deployment). The live production endpoint is automatically updated on every push to the `main` branch.

## 📂 Project Structure
This is part of a full-stack project split into three repositories:
*   **Customer Frontend:** https://deilariess0.github.io/Clean-Genie/
*   **Admin Dashboard:** https://booking-service-management-dashboar.vercel.app/
